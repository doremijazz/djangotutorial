# Environnement virtuel

| Action | Commande |
|---|---|
| Vérifier Python | `py -3.14 --version` |
| Créer l'environnement | `py -3.14 -m venv .venv` |
| Activer (PowerShell) | `.\.venv\Scripts\Activate.ps1` |
| Activer (CMD) | `.venv\Scripts\activate.bat` |
| Installer un paquet | `python -m pip install nom_paquet` |
| Lister les paquets | `python -m pip list` |
| Désactiver | `deactivate` |
